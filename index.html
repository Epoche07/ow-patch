오버워치 2 내전 커스텀 패치 노트

🛡️ 돌격 (탱커)
디몬 (버프 / 2차)
이전 패치로 인해 수직 기동성이 과도하게 향상되어, 높은 기본 능력치와 결합해 지나친 위력을 발휘했습니다. 이제 수직 이동은 가능하지만, 지형지물에 밀착해 활용해야만 고지대에 오를 수 있도록 기동성을 합리적으로 조정했습니다.
  • 돌진 강타(우클릭+좌클릭): 원하는 방향으로 자유롭게 돌진 가능, 이동속도 증가 (25m/s → 30m/s)
  • 추진기(Shift): 수직 상승 추진력 70% 대폭 감소 (이제 지형지물에 밀착해서 비벼 올라가야 고지대 등반 가능)
  • 메카 호출(궁극기): 호출 시간 단축, 공격력 대폭 증가 (75~150 → 150~300)
시그마 (버프 / 신규)
최근 다이브와 러시 조합이 강세를 보임에 따라, 포킹 조합 역시 충분한 경쟁력을 갖출 수 있도록 해당 조합의 핵심인 시그마의 유틸리티를 상향했습니다.
  • 실험용 방벽(우클릭): 재사용 대기시간 감소 (1초 → 0.5초), 파괴 시 재사용 대기시간 감소 (5초 → 2.5초)
라마트라 (버프 / 신규)
그동안 라마트라는 네메시스 형태로 변신한 후 가드만 올리고 경우가 많았습니다. 전반적으로 빨라진 게임 템포에 발맞춰 방벽의 가동률을 높이고 궁극기의 파괴력을 강화했습니다.
  • 공허 방벽(우클릭): 재사용 대기시간 감소 (12초 → 9초)
  • 절멸(궁극기): 지속시간 증가 (3~20초 → 4.5~30초)
레킹볼 (버프)
교전 중 탄창 부족으로 인해 확실한 마무리를 짓지 못하고 이탈해야 하는 답답한 상황을 완화하기 위해 기본 장탄수를 증가시켰습니다.
  • 무기: 탄창 증가 (80발 → 100발)
윈스턴 (버프)
전반적인 교전 템포가 빨라짐에 따라, 윈스턴이 적진에 진입하여 생존할 수 있는 여력을 높여주기 위해 방벽 생성기의 쿨타임을 감소시켰습니다.
  • 방벽 생성기(E): 재사용 대기시간 감소 (12초 → 11초)
라인하르트 (버프)
러시 조합에서 방벽을 전개한 상태로 적진을 향해 더욱 빠르고 위협적으로 전진할 수 있도록 이동 속도 페널티를 대폭 완화했습니다.
  • 방벽 방패(우클릭): 이동 속도 감소 페널티 완화 (30% → 15%)
로드호그 (버프 / 2차)
템포가 빨라진 전장에서 사슬 갈고리를 통한 변수 창출 기회를 확대했습니다. 또한 숨 돌리기의 이동 속도 증가 효과를 활용하여 위험한 순간에서 빠르게 벗어날 수 있도록 생존력을 부여했습니다.
  • 사슬 갈고리(Shift): 재사용 대기시간 감소 (7초 → 6초)
  • 숨 돌리기(E): 사용 중 이동 속도 30% 증가 버프 추가
도미나 (버프 / 2차)
선택률이 저조했던 도미나의 실전성을 전체적으로 끌어올렸습니다. 진입하는 적을 효과적으로 튕겨내고 난전에서 끈질기게 버틸 수 있도록 패시브를 강화했으며, 내구도가 부족했던 방벽의 가동률을 높여 진형 장악 능력을 개선했습니다.
  • 소닉 리펄서(Shift): 재사용 대기시간 감소 (7초 → 6초), 밀쳐내기 거리 20% 증가
  • 재조립(패시브): 획득하는 보호막 회복량 증가 (피해량의 75% → 100%)
  • 방벽 배열(우클릭): 재사용 대기시간 감소 (14초 → 10초)
정커퀸 (너프 / 2차)
정커퀸이 적진 깊숙이 파고들었을 때 받는 폭발적인 피해를 감당하기 어렵다는 점을 보완했습니다. 지휘의 외침 사용 시 짧은 무적 판정을 부여해 치명적인 공격을 흘려보내게 하고, 신규 패시브로 난전 지속력을 대폭 강화했습니다.
  • 기본 패시브: 받는 회복량 15% 증가
  • 지휘의 외침(Shift): 사용 시 정커퀸에게 0.8초 동안 순간 무적 부여
  • 아드레날린 촉진(패시브): [신규 효과] 과다 치유
    • 최대 체력 초과 회복 시 초과분만큼 임시 보호막 전환
    • 지속 시간: 일반 기술/근접 공격(3초), 궁극기(4.5초) 유지 후 소멸
    • 도륙으로 다수 적중 시에도 1명분의 수치만 보호막 적용
둠피스트 (조정 / 신규)
'하이 리스크 하이 리턴'이라는 둠피스트의 정체성을 한층 심화했습니다. 시선을 아래로 숙이는 세밀한 조작을 통해 전면 공격에 대한 방어 효율을 극대화할 수 있지만, 후방이 노출되었을 때의 위험도 역시 크게 증가하여 플레이어의 숙련도가 더욱 중요해졌습니다.
  • 파워 블락(E): 사용 중 시선을 아래로 40도 이상 숙일 경우, 받는 피해량 배율 150%로 증가 (정면으로 고개를 들면 즉시 원상 복구)
⚔️ 공격 (딜러)
겐지 (버프 / 2차)
다소 부족했던 겐지의 기본 체급을 상향 조정했습니다. 특히 용검이 발동되었을 때 상대에게 충분한 압박감을 주지 못하던 문제를 해결하여, 이름에 걸맞은 치명적인 위력을 발휘할 수 있게 개선했습니다.
  • 용검(궁극기): 공격력 증가 (110 → 125)
  • 수리검: 발당 공격력 증가 (27 → 29)
리퍼 (버프)
적과 근접해서 교전해야 하는 리퍼의 특성을 고려하여 기본 생존력을 높였습니다. 또한 죽음의 꽃 사용 도중 포커싱 당해 제압되는 상황을 방지하고자 능동적인 캔슬 기능을 추가했습니다.
  • 기본 스탯: 생명력 증가 (275 → 300)
  • 죽음의 꽃(궁극기): 사용 중 망령화로 궁극기 캔슬 가능
정크랫 (버프)
정크랫의 시그니처였던 평타-지뢰 암살 콤보를 부활시켰습니다. 또한 죽이는 타이어가 목표에 도달하기도 전에 너무 쉽게 파괴되던 현상을 완화하여 궁극기의 가치를 높였습니다.
  • 충격 지뢰(Shift): 공격력 10 증가
  • 죽이는 타이어(궁극기): 타이어가 받는 피해 33% 감소
프레야 (너프)
프레야의 지속 화력이 상대 진영에 지나치게 불합리한 압박을 가하고 있어, 기본 공격의 피해량을 적절한 수준으로 하향 조정했습니다.
  • 기본 공격(좌클릭): 발당 피해량 감소 (30 → 28.2)
위도우메이커 (버프)
기동성이 뛰어난 다이브 영웅들의 습격으로부터 위도우메이커가 스스로 거리를 벌리고 생존할 수 있는 여력을 조금 더 제공하고자 합니다.
  • 갈고리 발사(Shift): 재사용 대기시간 감소 (10초 → 8초)
  • 맹독 지뢰(E): 밟은 적의 이동 속도 30% 감소 (5초 지속)
애쉬 (버프 / 2차)
전투 중 재장전에 지나치게 많은 시간이 소모된다는 피드백을 수용하여, 탄약 보충 속도를 눈에 띄게 개선하여 딜 로스를 줄였습니다.
  • 바이퍼: 재장전 시 한 번에 총알 3발씩 장전
토르비욘 (너프 / 2차)
대장간 망치의 이동 속도 증가 옵션이 본래 의도와 달리 원거리 무기 사용을 저해하고 비정상적인 플레이를 고착화하는 경향이 있어 해당 수치를 하향했습니다.
  • 대장간 망치: 망치를 들고 있는 동안 이동 속도 10% 증가
솔저: 76 (버프 / 2차)
기본 체급이 다소 부족한 점을 보완하는 동시에, 매 교전마다 예측 불가능한 변수를 창출할 수 있도록 나선 로켓을 새롭게 개편했습니다. 행운이 따른다면 눈에 띄게 강력해진 화력을 체감할 수 있을 것입니다. 또한 전술 조준경의 실질적인 살상력을 높였습니다.
  • 나선 로켓(우클릭):
    • 직격 보상: 113 이상 피해 발생 시 쿨타임 즉시 4초로 단축 (기본 6초)
    • [신규 효과] 카지노: 76
      • 랜덤 데미지: 120~160 무작위 피해 (120: 40% / 130: 30% / 140: 15% / 150: 10% / 160: 5%)
      • 상태 이상 룰렛(자해 포함): 30% 확률로 발동
      • 화상 (3초간 초당 10의 지속 피해): 10% 확률
      • 치유량 50% 감소 (2초간 보라색 오라 이펙트 발생): 8% 확률
      • 해킹 (1초): 6% 확률
      • 넘어짐 (1초): 3% 확률
      • 빙결 (1초): 3% 확률
  • 전술 조준경(궁극기): 이동 속도 30% 증가 삭제, 대신 가하는 모든 피해량 25% 증가 (기본 공격력 19 → 23.75)
메이 (버프 / 2차)
고드름의 치명타 피해량을 상향하여 정교한 에임에 대한 확실한 보상을 부여했습니다. 아울러 탄창을 소모하는 대신 이동 속도를 대폭 끌어올릴 수 있는 신규 효과를 추가하여, 메이의 고질적인 기동성 문제를 해소했습니다.
  • 고드름(우클릭): 공격력 5 증가 (트레이서 헤드샷 원콤 가능)
  • 냉각총(좌클릭): [신규 효과] 아이스 스케이팅 (바닥에 쏘며 이동 시 이동 속도 40% 대폭 증가, 발사 중단 시 해제)
바스티온 (버프)
강습 모드가 종료되고 수색 모드로 전환되는 타이밍은 바스티온이 가장 취약해지는 순간입니다. 해당 시점에 추가 방어구를 부여하여 생존력을 보강했습니다.
  • 강습 모드(Shift): 활성화 중 이동 속도 10% 증가, 모드 종료 시 4초 동안 추가 방어구 50 부여
벤처 (버프)
처치 기여 시 이동기의 재사용 대기시간이 감소하는 효과를 추가하여, 벤처 특유의 적진을 파고드는 기동성을 한층 날카롭게 다듬었습니다.
  • 패시브: 처치 기여 시 잠복과 드릴 돌진의 쿨타임 1초 단축
한조 (버프)
포킹 딜러로서의 입지를 굳히기 위해 폭풍 화살의 횟수를 늘려 진입하는 적에 대한 억제력을 높였습니다. 음파 화살의 가동률 향상과 처치 시 기동 스킬 초기화를 통해 연속적이고 위협적인 교전이 가능해집니다.
  • 폭풍 화살(E): 화살 개수 증가 (5발 → 6발)
  • 음파 화살(Shift): 재사용 대기시간 감소 (12초 → 10초)
  • 패시브: 결정타(막타) 성공 시 이단 뛰기 쿨타임 즉시 초기화
시에라 (버프 / 2차)
추적 사격의 가동률을 높이고 진동 폭약에 이동 속도 감소 효과를 추가하여 러시 조합을 상대로 확실한 억제력을 발휘하도록 개선했습니다. 처치 시 기동 스킬이 초기화되어 더욱 속도감 있는 플레이가 가능해집니다.
  • 진동 폭약(E): 적중 시 적 이동 속도 20% 감소 (2초 지속)
  • 추적 사격(우클릭): 재사용 대기시간 감소 (10초 → 8초)
  • 앵커 드론(Shift): 결정타(막타) 성공 시 쿨타임 즉시 초기화
캐서디 (버프 / 신규)
다이브 영웅을 상대할 때 캐서디가 능동적으로 생존하고 추가적인 변수를 창출할 수 있도록, 처치 시 구르기가 초기화되는 기능을 새롭게 도입했습니다.
  • 패시브: 결정타(막타) 성공 시 구르기 쿨타임 즉시 초기화
벤데타 (버프 / 신규)
수차례의 너프 이후 픽률이 하락한 점을 고려하여, 가한 피해량에 비례해 생명력을 즉시 회복하는 능력을 부여해 다이브 조합에서의 전투 지속력을 높였습니다.
  • 패시브: 적에게 입힌 모든 피해량의 15%만큼 본인 생명력 즉시 흡혈
에코 (버그 픽스 / 신규)
내전 환경의 일관성을 위해, 에코가 궁극기로 적을 복제할 때 커스텀 밸런스가 적용된 버전으로 정상 복제되도록 시스템을 수정했습니다.
  • 복제(궁극기): 복제 시 대상 영웅의 커스텀 밸런스 패치 내역이 정상적으로 적용되도록 수정
✚ 지원 (힐러)
메르시 (리메이크 / 버그 픽스)
메르시 플레이어에게도 전황을 뒤집을 수 있는 공격적인 변수 창출 기회를 부여하고자 합니다. 발키리 상태에서 보다 위협적인 활약이 가능하도록 밸런스를 재조정했습니다.
  • 카두세우스 블라스터: [신규 효과] 차징 모드
    • 궁극기 미사용 중 공중 체공 시 활성화 (탄창 1발 고정, 발당 피해량 105로 대폭 증가)
    • 강화 탄환 발사 후 3초 쿨타임 적용 (공중 활공 중에는 쿨타임 없이 유지, 착지 시 일반 모드 즉시 복구)
